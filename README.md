# BIBIFI_Secure_Programming
Build It, Break It, Fix It project for Kent State Secure Programming, Fall 2026.

This is built like an art gallery. Users can move between rooms to view different pictures. They can also view events happening in the gallery. Employees can make events and see where people move, and admins can make users, rooms, and view session history.

(All photos on the application were taken by Ben Purdum)

# How to Run the Program
in the root directory, run

```docker compose up --build```

`database.db` is already initialized with `scheme.sql` and `seed.sql`, so you don't have to modify that.
